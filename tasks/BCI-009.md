Case-insensitive substring match. This list is append-only for later cards (AI-6's guard, AI-9's eval set import it) - do not remove entries.

Append (do not rewrite) one new "## AI" section to `docs/ARCHITECTURE.md` describing: the two-pass pipeline (selection call, then an adversarial verification call over only the selected ids, then code validation), that the model never authors a sentence a student reads, and the free-tier no-student-text rule.

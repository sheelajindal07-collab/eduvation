# De-identified session notes template

One copy of this template per session. Copy the block below; do not add
fields. Used by both `docs/research/moderator-script-round1.md` and
`docs/research/moderator-script-trial.md`.

## Never record

Name, phone number, email address, school name, home address, or any
other detail that could identify the participant, on this template or
anywhere in the repo. The participant code is the only identifier. If a
participant volunteers an identifying detail while thinking aloud,
paraphrase it out of the note (for example, write "named a nearby town"
rather than the town's name, if the town itself would narrow the
participant down within a small cohort).

Chandigarh is a Union Territory, not a state; this file uses "state" only
to match the naming convention of the other files in this series.

Honest scoping finding: Chandigarh is a **mixed** case, not a clean fit
for either "full independent stack" or "borrows a neighbour's system
entirely." It has **no exam board of its own** — Class 10/12 schooling
appears to run entirely on CBSE, with no distinct Chandigarh/UT board
located this session. But it does **not** simply defer engineering or
medical admission to Punjab's or Haryana's counselling bodies either — it
runs its own dedicated counselling infrastructure for both: the Joint
Admission Committee (JAC) Chandigarh for engineering/architecture, and
Government Medical College & Hospital, Sector 32 (GMCH-32)'s own
centralized admission process for MBBS/BDS/BHMS. Several of the exact
figures below (quota percentages, residency-duration thresholds) could
not be confirmed from primary-source text readable by the tools available
this session and are marked accordingly.

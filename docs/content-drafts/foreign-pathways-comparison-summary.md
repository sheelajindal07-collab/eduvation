### Notes on the cost column specifically

- All three "rough cost order-of-magnitude" figures above are themselves
  marked **Low confidence** inside their own source files, because each
  one is a researcher-constructed sum of a tuition range and a living-cost
  range that are independently of mixed confidence (some rows High —
  read directly from a primary government/statistical page; some rows
  Low — from secondary aggregator sites or blocked/unconfirmed primary
  pages). None of the three totals should be treated as a quote or a
  prediction for any individual student.
- Each country's file also records one number that **is** High confidence
  because it was read directly from a primary government source: Canada's
  CAD $23,448/year minimum proof-of-funds figure (IRCC, effective
  1 September 2026), the UK's £1,529/month (London) or £1,171/month
  (outside London) maintenance requirement (GOV.UK), and Australia's
  AUD $2,500 visa application charge from 1 July 2026
  (studyaustralia.gov.au). These are narrower, verified-source figures
  and are not the same thing as the wide combined cost ranges in the
  table above — see each source file for the distinction.
- No currency conversion to INR was attempted in any of the three source
  files or in this summary, since exchange rates fluctuate; this is
  flagged in each file as a product decision still to be made.

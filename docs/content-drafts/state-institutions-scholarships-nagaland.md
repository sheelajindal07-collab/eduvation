a state-run institution — flagged here as the most prominent

not confirmed from a primary source this session (see the note at the end

## 2. Nagaland State Merit Scholarship — the state-run post-matric scholarship

This is a scheme genuinely funded and administered by the State Government
of Nagaland (as opposed to the several centrally-funded schemes, e.g. the
NER/NEC "Merit Scholarship," Ishan Uday, or the ST Post-Matric Scholarship,
that the same state scholarship portal also lists and routes through the
National Scholarship Portal).

**Other schemes noted on the same portal for context (not used as the
primary answer, listed for the verifier's awareness):** the portal
(scholarship.nagaland.gov.in) lists 20+ schemes in total, including several
genuinely state-funded ones beyond the Merit Scholarship above — a "State
Medical Scholarship" (Active, state-funded, for medical students), a
"State Research Scholarship" (Active, state-funded, post-matric), a "State
Disability Scholarship" (Active, state-funded, Class I–VIII), and a
"Nagaland Government School Students' Meritorious Award" (state-funded,
primary through higher-secondary, offline application) — plus several
inactive state schemes (State Technical, State Agriculture, State
Horticulture) and numerous centrally-funded schemes routed through NSP.
None of these were opened for eligibility/amount detail this session; the
State Merit Scholarship above was selected as the primary answer because
it is Active, state-funded, and explicitly Post-Matric.

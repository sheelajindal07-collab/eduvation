**Scope note:** per `docs/DECISIONS.md` (2026-09-21, pilot scope widened
to all-India admission rules), this file covers Manipur's *state-level
admissions infrastructure* — the board, the counselling bodies and the
domicile rules — one level up from individual institutions, mirroring the

`docs/content-drafts/neet-ug-eligibility.md` and
`docs/content-drafts/jee-main-eligibility.md`) — only Manipur's *state
counselling* layer on top of them.

**Headline honest finding:** Manipur has its own Class 12 board and its
own state medical counselling authority, both confirmed directly from
official Government of Manipur sites this session. Engineering is the one
area where Manipur genuinely has **no separate state CET body or state
CET exam** — that part of the task's premise (checking whether a state CET
exists) resolved to "no": the state's only central Institute of National
Importance (NIT Manipur) uses the fully national JEE Main → JoSAA/CSAB
route with no state layer at all, and the state's one state-government
engineering college (MIT, Imphal) runs its own dual-track admission (a
JEE-qualified category plus its own institute-level entrance test for a
Non-JEE category) rather than a named, GUJCET-style state exam. This is a
genuine structural finding, not a gap in this session's research — see
section 2.

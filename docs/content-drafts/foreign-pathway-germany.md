## 2. General undergraduate application route for Indian students

| Fact | Value | Source | Access date | Confidence |
|---|---|---|---|---|
| No single centralised application portal | Unlike the UK's UCAS, Germany has no single national undergraduate application portal for all universities; recognition/processing of foreign applications is commonly done through a specialised service, and final admission decisions rest with each individual university | https://www.study-in-germany.com/en/plan-your-studies/requirements/entrance-qualification/ | 2026-09-21 | Medium — the page confirms university-by-university decision-making and describes uni-assist's role, but does not explicitly state "there is no centralised portal" in those words; this is this agent's synthesis of what the page describes, flagged for a verifier to confirm or rephrase |
| Qualification-recognition step | Applicants should first check whether their Class 12 qualification is recognised, using the DAAD's own entrance-qualification database (by country) and/or the Anabin database, which evaluates foreign secondary-leaving certificates | https://www.study-in-germany.com/en/plan-your-studies/requirements/entrance-qualification/ | 2026-09-21 | High — read directly from the DAAD-run portal |
| uni-assist | Many (not all) German institutions use uni-assist, a third-party service that "checks and evaluates foreign certificates" and issues a Preliminary Review Documentation (VPD) confirming which submitted certificates are recognised | Same source as above | 2026-09-21 | High |

`docs/content-drafts/neet-ug-eligibility.md`) — only Assam's *state
counselling* layer on top of it.

**Headline honest finding:** Assam is not a "thin infrastructure" state —
it has its own Class 12 board, its own engineering entrance exam and
counselling directorate, and its own NEET-UG state-quota counselling
authority, all distinct from any neighbouring state's system. The main
complication found this session is not absence of infrastructure but a
**recent institutional restructuring** (see section 1) that current
secondary sources describe inconsistently.

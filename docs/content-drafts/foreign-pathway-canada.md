## Scope note

This covers only the general (non-Quebec) route for an Indian Class 12
student applying to a Canadian undergraduate program: (1) study permit
basic legal requirements, (2) the general application route/order of
steps, and (3) an order-of-magnitude cost range (tuition + living). It
does **not** cover Quebec-specific rules (CAQ), scholarships, post-graduate
work permit (PGWP) eligibility, or permanent-residence pathways — those
would need separate research.

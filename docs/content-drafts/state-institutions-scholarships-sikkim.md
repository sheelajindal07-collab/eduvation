## Honest scope note

Sikkim does have its own named, dedicated state institutions in both
categories asked for: a genuine state-government-funded medical college
(HLSGMC) with fee and seat figures read verbatim from a signed official
notification, and a dedicated state scholarship portal
(scholarships.sikkim.gov.in) naming specific post-matric schemes. This is
not a "no infrastructure" state. The honest gaps are: (1) this session's
web-search tool budget was already exhausted before this topic began, so
all research had to be done by direct URL fetches rather than search,
which limited how many official pages could be found and opened; (2) the
scholarship portal's actual eligibility, income cap and amount figures sit
behind either a login wall or PDF links that returned server errors, so
those numbers are marked "not found" rather than estimated; and (3) no
distinctly Sikkim **state-government** engineering institution was
confirmed — the one well-known central institute (NIT Sikkim) is
central-government-funded, and the well-known engineering college most
students in Sikkim would recognise (SMIT) is private, so the medical
college was used as the primary answer instead, consistent with the
task's "engineering OR medical" instruction.

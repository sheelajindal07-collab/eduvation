## Honest scope notes for the reviewer

1. Goa does have identifiable, distinct state-level admissions and
   scholarship infrastructure of its own (a state Directorate of Technical
   Education running its own annual admission prospectus and merit
   process, and a state Directorate of Tribal Welfare / Directorate of
   Social Welfare running named state scholarship schemes on the state's
   own CM Scholarship Portal) — this is not a small state that simply
   defers to a neighbouring state's system. Both findings above were
   confirmed from Goa's own official `.gov.in` domains, not a
   neighbouring state's.
2. The most surprising finding this session is that GEC Goa's B.E.
   admission is JEE(Main)-based per the current (2026-27) official
   prospectus, not GCET-based as multiple aggregator sites currently
   state. This is exactly the kind of aggregator-vs-primary-source gap
   the project's non-negotiables exist to catch — a verifier should not
   let the aggregator figure into any published copy.
3. The Section 8.1 vs Section 8.3 fee discrepancy (Rs 57,100/semester vs
   Rs 55,000, both in the same official PDF) is reported as-is rather
   than resolved by guessing, per the "never guess a number and present
   it as sourced" rule.
4. This draft does not cover a government medical institution for Goa
   (Goa Medical College, Bambolim, was located and partially confirmed —
   official name, department, 200 MBBS seats per the same 2026-27
   prospectus, NEET UG-based admission per prospectus Rule 3.01 — but a
   full write-up was not completed in this session because the task
   asked for ONE institution and the engineering research above was
   already substantially complete). A reviewer/future session could
   extend this file or create a companion one for GMC if the pilot needs
   both.

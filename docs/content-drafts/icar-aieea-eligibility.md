## Important framing note before the tables

The task topic named this exam "ICAR AIEEA" (undergraduate). Primary-source
research this session found that **the undergraduate-level exam is no
longer branded AIEEA**. For the 2026–27 admission cycle, ICAR's own
Information Bulletin (read directly, in full) titles the UG entrance exam
**"CUET (ICAR-UG) — 2026"**, not "AIEEA-UG". Separately, NTA's own ICAR exam
page (found via search, summary only — see confidence note in row 1 below)
advertises only **"ICAR AIEEA (PG) and AICE-JRF/SRF (Ph.D.)"**, i.e. the
AIEEA name currently appears to be used for the postgraduate exam only, with
UG folded into the CUET (Common University Entrance Test) framework. A
verifier should confirm directly whether "AIEEA-UG" is still used
anywhere in current official material, or whether it is fully retired in
favour of "CUET (ICAR-UG)", before any student-facing content uses either
name.

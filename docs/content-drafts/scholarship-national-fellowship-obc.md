## Scope note — read this before anything else below

**This scheme does NOT apply to BCION Lite's Class 8–12 / undergraduate
pilot scope.** National Fellowship for OBC Students (NF-OBC) is a
**postgraduate research fellowship for full-time M.Phil. and Ph.D.
candidates only** — it requires the candidate to already hold a Master's
degree and to have qualified UGC-NET-JRF or UGC-CSIR NET-JRF. There is no
UG, Class 11–12, or school-level component to this scheme. It is included
here only because it was the assigned research topic; it is **not**
suitable content for this project's current pathway/eligibility/cost
screens and should not be added to the pilot's fact base as a student-facing
scholarship for the pilot's actual audience.

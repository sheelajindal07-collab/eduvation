## Honest scope note

Assam does have its own distinct state-level admissions and welfare
infrastructure for both categories requested (a government engineering
college with its own state entrance exam, CEE, run by the state's
Directorate of Technical Education; and a state-administered post-matric
scholarship channel run by a dedicated state directorate, on top of the
central NSP portal). This is unlike some very small states/UTs that lean
entirely on a neighbouring state's systems — that was not the case found
here.

## 4. Eligibility to APPEAR in JEE Main — subject requirement (important nuance)

| Fact | Value | Source | Access date | Confidence |
|---|---|---|---|---|
| Subject combination to APPEAR in the exam itself | Not found as an explicit requirement in Chapter 3 (Eligibility and Qualification) of the official Bulletin. Chapter 3 lists acceptable *qualifying examinations* (see above) but does not state that Physics/Mathematics/Chemistry must have been studied in order to register for and sit JEE Main Paper 1. Subject-combination and minimum-marks/percentile requirements were only found later in the Bulletin, in Chapter 5 ("Eligibility for Admission"), which governs admission to NITs/IIITs/CFTIs and B.Arch/B.Planning — not eligibility to appear in the exam. | Official Information Bulletin JEE (Main) 2026, read in full (Ch. 1–5 text extracted and searched this session) | 2026-09-21 | Medium — this is an absence-of-evidence finding (no explicit appear-time subject rule was found in Ch. 3), not a positive confirmation that no such rule exists anywhere in the document; a verifier should re-read Ch. 3 and the online Application Form's "Qualification Details" section in full to be certain. Many secondary/commercial sources (Careers360, Aakash, PW, Collegedunia, etc.) state a PCM-type subject rule as if it were an appear-time eligibility rule; this draft could not verify that framing against the primary text and flags it as likely conflating appear-eligibility with admission-eligibility. |
